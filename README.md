# Сайт Goldwar

Сайт сервера Lineage 2 Interlude x50 Goldwar: главная, рейд- и эпик-боссы, монстры и дроп по файлам сервера, где выбить предмет, отдельная вики по Interlude. Регистрация, кабинет и магазин остаются на ACP (acp.goldwar.net), сайт только ведёт туда ссылками.

Сайт статический: обычные HTML-страницы, стили и картинки. Ему не нужны PHP, база данных и CMS, подойдёт любой хостинг.

## Что в репозитории

| Папка | Что это |
| --- | --- |
| `site/` | Готовый сайт. Это содержимое корня хостинга (public_html). |
| `source/` | Исходники: генератор, шаблоны, стили, картинки и видео, данные. Нужны, чтобы что-то поменять и пересобрать сайт. |

## Как выложить на хостинг

1. Скачайте репозиторий: зелёная кнопка **Code** → **Download ZIP**.
2. Скопируйте содержимое папки `site/` в корень сайта на хостинге (обычно `public_html`). Скрытый файл `.htaccess` тоже нужен.
3. Сборка в `site/` сделана для тестового адреса: в `.htaccess` стоит запрет индексации (`X-Robots-Tag: noindex`). На боевом goldwar.net удалите первую строку `.htaccess` или пересоберите сайт с `GW_PROD=1` (ниже).

Ссылки canonical, sitemap.xml и разметка уже указывают на `https://goldwar.net`.

## Как поменять и пересобрать

Нужен Python 3.10+.

```
cd source
pip install -r requirements.txt
python build.py              # тестовая сборка (с noindex)
GW_PROD=1 python build.py    # боевая сборка для goldwar.net
```

Готовый сайт появляется в `source/dist/`, его содержимое и выкладывается на хостинг.

Что где менять:

| Что | Где |
| --- | --- |
| NPC, рейд- и эпик-боссы, их дроп и спойл | `source/data/npcs.xml` – файл сервера, сайт берёт данные прямо из него |
| Названия и описания предметов сервера | `source/data/itemname.txt` – ItemName из клиента |
| Ссылки на ACP, Telegram, Discord, соцсети, меню | блок `SITE` в начале `source/build.py` |
| Тексты страниц | `source/templates/*.html` и тексты в `source/build.py` |
| Цвета, шрифты, сетка | `source/static/css/site.css` (переменные в `:root`) |
| Логотип, фоновые картинки, видео | `source/assets/` |

Проверка SEO после правок: `python seoaudit.py` – обходит `dist/` и показывает дубли и длины title/description, битые ссылки, страницы без входящих ссылок и расхождения с sitemap.

Видео главной склеены в бесшовный цикл скриптом `source/loopvid.sh` (нужен ffmpeg).

## Данные вики

Вики по Interlude (классы, предметы, монстры, зоны, квесты) собрана из открытого набора данных [lineage2-api](https://github.com/cuteshaun/lineage2-api) (лицензия MIT, текст лицензии в `source/vendor/l2api/LICENSE`). Страницы сервера (боссы, дроп, «где выбить») строятся только из файлов Goldwar.

## Предпросмотр

Пока сайт не перенесён на goldwar.net, его можно посмотреть на GitHub Pages: https://vaetn.github.io/goldwar-site/ (закрыто от индексации). Копия обновляется сама после каждого изменения в репозитории.
